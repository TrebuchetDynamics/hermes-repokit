## Immutable upstream selection

- Hermes' [community catalog entry](https://github.com/NousResearch/hermes-agent/blob/5ce2c7d5aa15741da3569bea0fc693629b634ce5/plugin-catalog/nerve.yaml) names plugin `nerve`, version `0.3.0`, and pins `keeltrace/hermes-nerve` commit [`b9e78dd5e00cf1117c563cada4d563a56f66e609`](https://github.com/keeltrace/hermes-nerve/tree/b9e78dd5e00cf1117c563cada4d563a56f66e609). Its declared surface is 16 tools and nine hooks; `requires_hermes` is `>=0.21`. The [catalog policy at the same Hermes revision](https://github.com/NousResearch/hermes-agent/blob/5ce2c7d5aa15741da3569bea0fc693629b634ce5/plugin-catalog/README.md) says a catalog install checks out exactly its reviewed SHA. This catalog pin is the reproducible candidate, not the moving Nerve branch.
- The [catalog disclosure](https://github.com/NousResearch/hermes-agent/blob/5ce2c7d5aa15741da3569bea0fc693629b634ce5/plugin-catalog/nerve.yaml) says default Jev turn admission sends up to 12,000 prompt characters and redacted tool previews to a configured hosted Jev provider. A local-Laya deployment therefore has to set `reflex_backend: laya` before enabling Nerve, and qualify all enabled Nerve modules that may call Reflex.
- The catalog pin predates upstream [`4c921f7101f3a0c63742f8de561afdec7500b0a2`](https://github.com/keeltrace/hermes-nerve/tree/4c921f7101f3a0c63742f8de561afdec7500b0a2). The relevant Laya client, sidecar, manifest, and Kanban work files are byte-identical at these two commits, but the profile configuration helper is **different** (see below). Do not infer a catalog re-pin from the newer upstream branch.

## Profile-aware install and configuration contract

- Hermes documents [`hermes -p NAME`](https://github.com/NousResearch/hermes-agent/blob/5ce2c7d5aa15741da3569bea0fc693629b634ce5/website/docs/user-guide/multi-profile-gateways.md) for named profiles, and [`hermes plugins install <catalog-name>`](https://github.com/NousResearch/hermes-agent/blob/5ce2c7d5aa15741da3569bea0fc693629b634ce5/website/docs/user-guide/features/plugins.md) for catalog entries. The source-qualified candidate sequence is `hermes -p PROFILE plugins install nerve --no-enable`, write profile config, then `hermes -p PROFILE plugins enable nerve`. Enabling and actual loading still require a selected Hermes image/profile runtime test. Nerve's alternative [copy/install script](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/scripts/install_dev17_profile.sh) copies its whole source tree to `$HOME/.hermes/profiles/$PROFILE/plugins/hermes-nerve`, preserves old directories as timestamped backups, and enables `nerve`; it is a separate path with host-`HOME` assumptions, not the catalog installer.
- The [manifest](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/plugin.yaml) says `name: nerve`. Hermes [`ctx.get_config`](https://github.com/NousResearch/hermes-agent/blob/5ce2c7d5aa15741da3569bea0fc693629b634ce5/hermes_cli/plugins.py#L269) reads `plugins.entries.<plugin_id>.settings.<key>` from the active profile config. For Laya, the required shape is:

  ```yaml
  plugins:
    entries:
      nerve:
        settings:
          nerve_profile: lean
          reflex_backend: laya
          reflex_laya_base_url: http://127.0.0.1:8765
          reflex_laya_model: convaiinnovations/laya-typed-decisions
  ```

  `lean` is an example Nerve personality, not a required Hermes profile name. Nerve's [profile resolver](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/hermes_nerve/config_resolver.py) accepts `nerve_profile` in plugin settings or `$HERMES_HOME/nerve/profile.json`, uses Legacy behavior when neither exists, and applies explicit module overrides. The [preset map](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/hermes_nerve/profiles.py) enables work supervision for Lean and Marie Kondo; Operator omits it. Selected profiles omit disabled module schemas/hooks at [registration](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/__init__.py).
- **Catalog-pin defect:** [`scripts/configure_reflex_profile.py` at `b9e78dd`](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/scripts/configure_reflex_profile.py) writes `plugins.entries.hermes-nerve.settings`, which `ctx.get_config` for plugin ID `nerve` does not read. The [newer helper at `4c921f7`](https://github.com/keeltrace/hermes-nerve/blob/4c921f7101f3a0c63742f8de561afdec7500b0a2/scripts/configure_reflex_profile.py) fixes the key and writes only requested options. At the catalog pin, configure `plugins.entries.nerve.settings` through the native profile config surface; do not rely on that helper. A move to the newer commit would require its own explicit immutable pin and qualification.

## Provider-neutral Reflex and Laya sidecar

- The [Reflex factory](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/hermes_nerve/reflex/config.py) accepts `jev`, `laya`, `openjev`, or `shadow`; `jev` is default. `laya` selects `LayaClient`; `shadow` keeps Jev authoritative while comparing Laya by default. The [DecisionEngine](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/hermes_nerve/engine.py) redacts state/questions and calls a provider with `system_one(state=..., questions=...)`, so Nerve's work logic uses the same typed decision seam across providers. Shadowing is not a local-only mode.
- Current code defaults to model ID `convaiinnovations/laya-typed-decisions`, sidecar URL `http://127.0.0.1:8765`, and five-second client timeout. The [sidecar setup script](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/scripts/setup_laya_dev17.sh) installs `laya==0.3.3` in a separate venv; the [sidecar](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/hermes_nerve/reflex/laya_service.py) loads the model once with `laya.load(model, device=...)`. It exposes `GET /healthz` (`ok`, `provider`, `model`, `transport`) and `POST /v1/systemone`. The older [Dev15b guide](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/docs/DEV15B_LAYA_INTEGRATION.md) still describes `convaiinnovations/laya:typed-decisions` and `laya==0.3.5`; use the current code and [Dev17 guide](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/docs/DEV17_OPEN_SOURCE_VALIDATION.md) for this pin.
- The [client](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/hermes_nerve/reflex/laya.py) sends JSON `{state, questions, model}`. A `questions` object has named typed questions; Nerve's [engine validation](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/hermes_nerve/engine.py) allows at most 16 questions of type `choice`, `score`, or `noul`, with instructions and type-appropriate criteria. Its [HTTP test](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/tests/test_reflex_laya_dev15b.py) exercises `choice` criteria such as `{WATCH: continue, REPLAN: change plan}`. The sidecar ignores request `model` for loading, evaluates under an inference lock, caps the JSON body at 1 MiB, and responds with `{id, model, provider, transport, answers, usage, latency_ms}`. The client checks the returned model string against its configured model, labels execution `LOCAL_ONLY`, and does not report a live provider call. A missing response `model` falls back to the requested value in client code, so this is a model-name check, not an independent checkpoint attestation.
- By default the sidecar binds loopback; it refuses a non-loopback bind without `HERMES_REFLEX_LAYA_TOKEN`. The client permits HTTP only for loopback names and requires HTTPS for a remote URL. The [Dev17 guide](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/docs/DEV17_OPEN_SOURCE_VALIDATION.md) describes an SSH loopback tunnel and `scripts/check_laya_sidecar.py` smoke. The model repository revision/weights digest is **not pinned** by these launch scripts or the sidecar CLI. Model download, actual checkpoint identity, GPU/CPU behavior, HTTP reachability from the selected Hermes container, and inference correctness remain runtime qualification gates.

## Same-card review and authority limits

- Nerve's [Kanban adapter](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/hermes_nerve/work/kanban_adapter.py) delegates review to native `kanban_db.request_review(..., reviewer=..., expected_run_id=..., force=False)` and completion to native `complete_task(..., expected_run_id=...)`. Its [budget handoff hook](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/hermes_nerve/work/hooks.py#L691) calls registered `kanban_request_review`, optionally adding configured `work_reviewer`; it says the orchestrator/reviewer owns final COMPLETE/CHANGES/BLOCK for budget pressure. Nerve's [README](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/README.md) also describes a controller-owned native `kanban_complete` path after verified DoD PASS.
- This source establishes exact task/run fencing and Nerve's own DoD/evidence gate, **not a distinct-actor same-card review guarantee**. The [Nerve tool](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/hermes_nerve/work/tools.py) accepts caller-provided `actor` for contract binding and caller-provided `reviewer` for review handoff; the [supervisor](https://github.com/keeltrace/hermes-nerve/blob/b9e78dd5e00cf1117c563cada4d563a56f66e609/hermes_nerve/work/supervisor.py) checks that the actor string is one of `orchestrator`, `reviewer`, or `human`, not that it belongs to an independently authenticated second actor. No Nerve source inspected compares the same card's maker, worker, reviewer and approving actor or requires a separate review before its controller completion path. The actual selected Hermes Kanban actor/review semantics must be qualified separately; Nerve cannot be cited as proof of them.
